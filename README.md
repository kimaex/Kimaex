
# Kimaex

Naira-first digital asset platform built to make crypto and DeFi more accessible.

## Features

- React dashboard
- Naira-denominated portfolio
- Responsive mobile interface
- Asset overview
- Swap interface
- Futures interface
- Wallet interface
- Activity navigation
- Beginner and Pro interface modes

## Installation

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```

## Technology

- React
- Vite
- JavaScript
- CSS
- Lucide icons

## Disclaimer

This version is a frontend prototype. It does not process real financial transactions or store customer funds.

Real blockchain functionality, wallet integration, swap execution, futures trading, authentication, security and regulatory requirements must be implemented before production.
